# THAKI · Antofagasta

Sitio original construido con Next.js, TypeScript y Tailwind CSS.

- `/`: producción de eventos corporativos, culturales y comunitarios en Antofagasta. Presentación cálida con composición gráfica y movimiento en CSS, respetando la preferencia de movimiento reducido.
- `/tarapaca`: antecedente separado de la propuesta exploratoria de Iquique y Tarapacá.
- `/agentes-instagram`: modelo histórico de agentes de la etapa Tarapacá.
- `/encuesta`: diagnóstico de capacidades, con enfoque en Antofagasta.

NorthAcoustics se presenta como colaborador estratégico independiente, con alcance definido para cada encargo.

El documento societario utilizado para orientar el contenido está marcado como borrador; el sitio no acredita constitución ni habilitaciones regulatorias.

## Desarrollo y validación

```sh
npm ci
npm run build
npm run typecheck
npm run start
```

Se mantiene la dirección de Netlify existente y el destino de la encuesta. La portada usa una ilustración abstracta, sin presentar eventos realizados ni clientes como experiencia de la nueva empresa. La idea de plataforma se conserva como articulación de colaboradores por proyecto. Los servicios son alcances a acordar, sin afirmar equipamiento propio ni relaciones formales con NorthAcoustics.
